# demo-mods

Example mods used to exercise the loader and as copy-paste starting points:
- car-skin — register a custom car style (Tier 1 registry)
- custom-block — add a track piece (Tier 1 registry)
- physics-tweak — observe/adjust physics via in-worker events (Tier 1 + worker environment)
- ui-widget — add a HUD widget (Tier 1 registry)

Added in a later milestone.
